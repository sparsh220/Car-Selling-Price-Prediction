# 🚗 Car Selling Price Prediction

## About the Project
This project predicts the estimated selling price of a used car based on its details, such as brand, year, kilometers driven, fuel type, seller type, owner, transmission, mileage, engine,seats and maximum power.

## Technologies Used
- Python
- Pandas and Scikit-learn
- Flask
- HTML and CSS
- Joblib
- GitHub and Render

## Machine Learning Model
I used a Random Forest Regressor to predict the selling price of used cars.

I applied RandomizedSearchCV for hyperparameter tuning to find a better-performing model.



## How to Use
1. Open the web application.
2. Enter the car details.
3. Click the Predict button.
4. View the predicted selling price.
